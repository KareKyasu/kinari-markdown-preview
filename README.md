# Kinari

> 晒さぬ紙の、やわらかな白。
> その頁に、ことばをしたためる。

Kinari（きなり）は、VS Code の Markdown プレビューを、生成りの紙のように仕立てる拡張機能です。
画面のまぶしい白に目が疲れた日も、ほんのり温かな紙の色が、読むひとときを静かに整えてくれます。

![Kinari のスクリーンショット](images/screenshot.png)

## 趣（おもむき）

- **七つの和紙** — 生成りをはじめ、季節や景色を映した七色の和紙から、その日の気分でお選びいただけます。
- **やわらかな文字** — 丸みのあるゴシック体と、ゆとりある字間。ことばが肩の力を抜いて並びます。
- **ひとつの調子** — 見出し、引用、表、キーの表示、マーカー、コードの色分けまで、紙の色に合わせて染め分けました。
- **夜でも紙のまま** — VS Code が夜の装い（ダークテーマ）でも、プレビューだけは明るい紙のままお使いいただけます。

## 七つの和紙

![七つの和紙の色](images/papers.png)

| 名 | 設定値 | 色の便り |
| --- | --- | --- |
| 生成り（きなり） | `kinari`（既定） | 晒さぬ木綿の、ほんのり黄みを帯びた白。いつもの一枚。 |
| 鳥の子（とりのこ） | `torinoko` | 鶏の卵の殻を思わせる、淡い玉子色。上質な和紙「鳥の子紙」に因みます。 |
| 薄桜（うすざくら） | `usuzakura` | 春霞にほどける、桜の花びらのごく淡い紅。 |
| 若菜（わかな） | `wakana` | 雪間に萌え出る若菜の、やさしい黄緑。 |
| 藍白（あいじろ） | `aijiro` | 藍甕にほんのひと浸し。藍染めのうち、もっとも白に近い色。 |
| 海（かい） | `kai` | 凪の浅瀬に陽の差すような、澄んだ青緑。 |
| 白練（しろねり） | `shironeri` | 練り上げた絹のような、ほのかに温もりのある白。 |

### 和紙の選び方

プレビュー右上の 🎨 をそっと押すと、和紙の一覧がひらきます。
矢印キーで巡るたびに頁の色が移ろいますので、見比べながらお選びください。Enter で決まり、Esc を押せば元の色に戻ります。

コマンドパレット（`Cmd+Shift+P`）の「Kinari: 和紙を選ぶ」からも、同じ一覧をお呼びいただけます。

## お迎えのしかた

[Releases](https://github.com/KareKyasu/kinari-markdown-preview/releases) から `.vsix` をお受け取りのうえ、次のようにお迎えください。

```bash
code --install-extension kinari-1.2.1.vsix
```

お手元で仕立てる場合は、こちらを。

```bash
npx @vscode/vsce package
```

お迎えしたあとは、Markdown のプレビュー（`Cmd+Shift+V`）をひらくだけ。何も設定せずとも、生成りの紙でお目にかかれます。

## 設定

| 設定 | 説明 |
| --- | --- |
| `kinari.paper` | 和紙の色（上の表の設定値）。既定は `kinari` |
| `markdown.preview.fontSize` | 文字の大きさ（VS Code 標準の設定。既定は 14） |

## 心得

- 書体（丸ゴシック）と行間（1.65）は Kinari の仕立てに含まれるため、`markdown.preview.fontFamily` と `markdown.preview.lineHeight` は効きません。
- `kinari.paper` はウィンドウごとの設定です。マルチルートワークスペースで、フォルダごとに和紙を変えることはできません。
- VS Code 1.78 以降でお使いください。
